# GtStore v6.10 — Campaign Studio

В административную панель добавлен визуальный раздел CRM-кампаний поверх backend v6.9.

## Возможности

- создание и редактирование Telegram-кампаний;
- сегменты: все, новые, повторные, VIP;
- немедленная и запланированная отправка;
- отмена кампании;
- фильтрация по статусу;
- метрики аудитории, доставок и ошибок;
- журнал доставки по каждому Telegram ID;
- блокировка редактирования отправленных кампаний.

## Проверка

```bash
npm run v6:campaign-ui:test
npm run v6:test
```
