# GtStore v6.2 — Import Center & Media Storage

## Реализовано

- загрузка JPEG, PNG, WebP и GIF через защищённый API;
- лимит 8 МБ и проверка MIME-типа;
- локальное медиахранилище с безопасными UUID-именами;
- выдача медиа с immutable cache headers;
- медиагалерея товара, сортировка и выбор обложки;
- импорт CSV без сторонних зависимостей;
- импорт XLSX/XLS через пакет `xlsx` после `npm install`;
- автоматическое определение листов «Категории» и «Товары»;
- preview с ошибками, предупреждениями и первыми строками;
- подтверждаемая запись каталога;
- автоматическое создание категорий;
- режим пропуска некорректных строк;
- интеграционные тесты загрузки медиа и CSV-импорта.

## Запуск

```bash
npm run v6:api
npm run v6:admin
```

Админка: `http://127.0.0.1:4173`
API: `http://127.0.0.1:4000`

## Проверка

```bash
npm run v6:test
```

Для XLSX:

```bash
npm install
```

CSV и медиахранилище работают на Node.js 18+ без дополнительных пакетов.
