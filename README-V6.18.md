# GtStore v6.18 — Delivery Core

Добавлен единый модуль способов доставки и отправлений.

## Возможности

- провайдеры: самовывоз, курьер магазина, СДЭК, Boxberry, Почта России;
- настройка стоимости и порога бесплатной доставки;
- публичный расчёт вариантов доставки;
- создание отправления по заказу;
- трек-номер и публичное отслеживание;
- статусы created, ready, shipped, in_transit, delivered, cancelled, failed;
- синхронизация shipped/delivered со статусом заказа;
- журнал событий отправления;
- административный раздел «Доставка».

## Проверка

```bash
npm run v6:delivery:test
npm run v6:delivery-ui:test
npm run v6:test
```
