# Roadmap after v5.0

## Milestone 5.1 — Runtime wiring
1. Create Express v5 router over the new services.
2. Add request context, authentication and tenant middleware.
3. Generate Prisma client and initial migration.
4. Add PostgreSQL transaction-backed repositories.
5. Run contract and integration tests in CI.

## Milestone 5.2 — Admin application
1. Add Vite and React entry point.
2. Connect ProductEditor to live v5 API.
3. Build category tree and Excel import wizard.
4. Build order board and customer profiles.
5. Add accessibility and responsive navigation.

## Milestone 5.3 — Storefront builder
1. Persist block drafts.
2. Add banner and tile image uploads.
3. Add mobile preview presets for Telegram and MAX.
4. Publish immutable storefront versions.
5. Add rollback and scheduled publication.

## Milestone 5.4 — Commerce operations
1. Payment-provider adapters and webhook reconciliation.
2. Geographic delivery zoning and map editor.
3. Referral ledger settlement on paid/completed orders.
4. Notification templates and automatic replies.
5. Analytics event pipeline and dashboards.

## Milestone 5.5 — Ecosystem
1. MySklad catalog and stock synchronization.
2. 1C exchange profile.
3. Bitrix24 contacts and deals.
4. Public REST API and signed webhooks.
5. SDK and integration documentation.
