# Vision Design System

## Направление
Тёмная графитовая основа, медно-янтарный спектр, мягкое стекло и редкие световые акценты. Динамика должна усиливать иерархию, а не отвлекать.

## Правила
- Один активный переливающийся акцент на экран.
- Анимация 180–650 мс для действий, 8–24 с для ambient-слоёв.
- Интерфейс сохраняет контраст WCAG AA.
- `prefers-reduced-motion` отключает декоративную динамику.
- Основной шрифт: Inter/Manrope; цифры — tabular; заголовки плотные, без чрезмерного трекинга.
- Радиусы: 12, 16, 22, 30 px. Не использовать случайные значения.
- Состояния: default, hover, focus, active, loading, success, warning, danger, disabled.
