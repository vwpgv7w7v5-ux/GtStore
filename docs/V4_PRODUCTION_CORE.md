# GtStore v4.0 Production Core

Эта версия начинает архитектурный переход от монолитного прототипа к модульной commerce-платформе. Старый интерфейс и API сохранены для обратной совместимости, а критические доменные процессы постепенно переносятся в `src/`.

## Реализовано в модульном ядре

- последовательные транзакции JSON-репозитория с ревизиями;
- типизированные прикладные ошибки и валидация входных данных;
- дерево категорий и подкатегорий;
- CRUD товаров, уникальность SKU, галерея и вариации;
- создание заказов с резервированием/списанием остатков;
- конечный автомат статусов заказа и возврат остатка при отмене;
- реферальный ledger со статусами `pending`, `available`, `used`;
- общий контракт каналов и адаптеры Telegram/MAX;
- реестр интеграций МойСклад, 1С, Bitrix24 и Custom API;
- API `/api/v4/*`;
- минимальные интеграционные тесты доменного ядра.

## Граница версии

PostgreSQL, Prisma, Redis, React и объектное хранилище ещё не подключены. V4.0 создаёт рабочую доменную границу, чтобы следующая миграция не потребовала повторного переписывания бизнес-правил.

## V4 API

- `GET /api/v4/health`
- `GET|POST /api/v4/catalog/categories`
- `PATCH|DELETE /api/v4/catalog/categories/:id`
- `GET|POST /api/v4/catalog/products`
- `PATCH|DELETE /api/v4/catalog/products/:id`
- `GET|POST /api/v4/orders`
- `POST /api/v4/orders/:id/transition`
- `POST /api/v4/referrals`
- `GET /api/v4/referrals/summary`
- `GET /api/v4/integrations`
