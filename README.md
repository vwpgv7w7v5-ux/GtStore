# GtStore v4.0 — Production Core

Рабочий переход от монолитного прототипа к модульной commerce-платформе для Telegram, MAX и внешних CRM.

## Запуск

```bash
cp .env.example .env
npm install
npm start
```

- Админка: `http://localhost:3000/admin`
- Витрина: `http://localhost:3000/shop/demo`
- Демо-вход: `kirill@gtstore.app` / `gtstore2026`

## Проверка

```bash
npm run verify
npm run stats
```

## Что действительно работает в V4 core

- модульные сервисы каталога, категорий, заказов и рефералов;
- дерево подкатегорий;
- уникальные SKU и вариации;
- безопасные переходы статусов заказа;
- списание и возврат остатков;
- отдельный реферальный ledger;
- контракты Telegram/MAX;
- реестр МойСклад, 1С, Bitrix24 и универсального API;
- API `/api/v4/*`;
- автоматические тесты core-сценария.

Старые маршруты сохранены, чтобы текущая админка и витрина продолжали запускаться. Детали: `docs/V4_PRODUCTION_CORE.md`.
