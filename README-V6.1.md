# GtStore v6.1 — Catalog Engine

## Запуск

```bash
npm run v6:api
npm run v6:admin
```

Админка: http://127.0.0.1:4173  
API: http://127.0.0.1:4000/api/v6

## Реализовано

- дерево категорий и подкатегорий;
- создание, изменение и безопасное удаление категорий;
- фильтрация каталога по категории, статусу и поиску;
- редактор товаров с изображениями и вариациями;
- уникальные SKU товара и вариаций;
- массовая публикация, скрытие и изменение остатка;
- удаление и редактирование товаров;
- предварительная серверная проверка импорта;
- обновлённый двухпанельный интерфейс каталога;
- интеграционный тест полного каталожного сценария.
