# GtStore v6.3 — Storefront Builder

## Запуск

```bash
npm run v6:api
npm run v6:admin
npm run v6:storefront
```

- API: http://127.0.0.1:4000
- Админка: http://127.0.0.1:4173
- Витрина: http://127.0.0.1:4174/?shop=<slug-магазина>

## Реализовано

- визуальный конструктор витрины;
- блоки: баннер, категории, товары, текст, отступ;
- изменение порядка блоков;
- настройки темы и SEO;
- отдельный черновик;
- публикация снимка витрины;
- журнал версий и восстановление;
- публичный API магазина по slug;
- отдельная адаптивная web/Telegram Mini App витрина;
- фильтр по категории и локальная корзина.
