# GtStore v6.12 — Automation Studio

This release adds the missing visual administration layer for the v6.11 automation engine.

## Included

- Automation navigation section
- Rule cards and aggregate execution metrics
- Filters for active and disabled rules
- Create/edit modal with trigger and order-status configuration
- Message variable insertion
- Delay configuration from 0 minutes to 7 days
- Enable/disable switch
- Execution log with pending, sent and failed states
- Rule deletion

The UI uses the existing v6.11 API and does not change execution semantics.
